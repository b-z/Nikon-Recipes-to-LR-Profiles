# 安装 0.2.0 配置文件

1. 解压，在 LR / Camera Raw 配置文件浏览器中选择「导入配置文件」，手动导入 `profiles/` 中的 `.xmp`。不需要额外 DCP 或安装包。
2. 如果没有显示，重启 LR。打开 **Nikon Recipes LR 0.2** 分组选择风格。
3. 数量支持 0–200%，温和应用可先试 30–50%。继续正常调整曝光、白平衡等参数。

全部 236 款尼康转换均为 **Y8**：用平滑样条拟合后采样成 32³ RGB 表，牺牲少量格靶精度换取更平滑的渐变。上一版 Y7 中仍有断层的 58 款，作者已用 Y8 在多张实拍上复查，未见断层；其余 178 款未逐一用 Y8 复查。色彩断层仍是已知风险，尤其是天空、焦外和高强度。仅 Nikon Z8 实测。

0.2.0 使用新的名称、分组和 UUID，可以与 0.1 并存。不再需要时可删除 **Nikon Recipes LR 0.1** 分组。

逐款作者和评估信息见配置文件及 `manifest.json`。原始 NP3 不打包，链接 https://github.com/shouryan01/Nikon-Recipes 。工具与项目原创转换资源采用附带 MIT 及 PROFILE_LICENSE 说明，照片另行授权。富士模拟不包含在本包中。

评分和对比图：https://github.com/b-z/Nikon-Recipes-to-LR-Profiles 。对应英文说明版本 0.2.0。

# 安装 0.1.0 配置文件

1. 解压，在 LR / Camera Raw 配置文件浏览器中选择「导入配置文件」，手动导入 `profiles/` 中的 `.xmp`。不需要额外 DCP 或安装包。
2. 如果没有显示，重启 LR。打开 **Nikon Recipes LR 0.1** 分组选择风格。
3. 数量支持 0–200%，温和应用可先试 30–50%。继续正常调整曝光、白平衡等参数。

包含全部 236 款尼康转换（19 款 YC7 + 217 款 YC4）。色彩断层是已知问题，尤其是天空、焦外和高强度。仅 Nikon Z8 实测。此前 18 款 YC7 通过作者实测，Bleach Blue 仍有残留断层；不代表全部配方与照片通过验收。富士模拟不包含在本包中。

逐款作者和评估信息见配置文件及 `manifest.json`。原始 NP3 不打包，链接 https://github.com/shouryan01/Nikon-Recipes 。工具与项目原创转换资源采用附带 MIT 及 PROFILE_LICENSE 说明，照片另行授权。

评分和对比图：https://github.com/b-z/Nikon-Recipes-to-LR-Profiles 。对应英文说明版本 0.1.0。

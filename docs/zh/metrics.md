# 分数与已知问题

主拟合分是实际交付颜色表在已有标靶上的 CIEDE2000：Adobe RGB 转 D65 Lab，kL=kC=kH=1；排除输入或目标任一通道 <0.0005 或 >0.999 的色块。平均值、中位数、p95 和样本数逐款列出。它不是独立真实照片测试。YC7 的历史留出分数另列，不等于新的拍摄场景。

断层风险分统计 32³ 表的 351,726 个四面体内部和跨网格面的 RGB 导数变化，包括 p99、最大值与 RMS。它是结构风险，不是可见断层的数量、ΔE 或通用通过阈值。连续变换仍可能在导数突变处显露轮廓；真实风格中的陡曲线也会影响分数。

LeicaSTD、At Dusk、Blue Hour 使用确认关闭细节设置的 NX 真值；其余历史标靶未统一关闭细节设置，逐款标注。四张样本对比默认是 Adobe Standard 输出上的数学预览，不是 NX/LR 真值对照；实际 ACR 验证另列。中性偏色的大面积影响、细节遮蔽与美观度不是一个平均 ΔE 能表达的。

色彩断层、拟合色差和机身差异均是已知问题。数值不能代替实际 LR 验收，尤其是天空、焦外和 200% 强度。JPEG 和 8 位显示预览本身也可能制造或隐藏断层。完整定义见 [English](../en/metrics.md)，版本 0.1.0。

网站当前 236 款均已用 Y7 重新拟合；Previous LR conversion 保留旧版对比。GitHub 历史 Release 包尚未随网站部署更新。

2026-10-10 复核：Y7 条纹显著减少；58 款仍有少量条纹，使用灰色三角标记，取代所有旧标记。未标记不等于所有场景都无条纹。

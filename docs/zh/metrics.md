# 分数与已知问题

目录列出的是 Release 实际交付颜色表（0.2.0 起为 Y8）的分数，并附 Y7 分数对照。主拟合分是交付颜色表在已有标靶上的 CIEDE2000：Adobe RGB 转 D65 Lab，kL=kC=kH=1；排除输入或目标任一通道 <0.0005 或 >0.999 的色块。平均值、中位数、p95 和样本数逐款列出。它不是独立真实照片测试。固定留出色块的分数另列，不等于新的拍摄场景。

断层风险分统计 32³ 表的 351,726 个四面体内部和跨网格面的 RGB 导数变化，包括 p99、最大值与 RMS。它是结构风险，不是可见断层的数量、ΔE 或通用通过阈值。连续变换仍可能在导数突变处显露轮廓；真实风格中的陡曲线也会影响分数。

LeicaSTD、At Dusk、Blue Hour 使用确认关闭细节设置的 NX 真值；其余历史标靶未统一关闭细节设置，逐款标注。四张样本对比默认是 Adobe Standard 输出上的数学预览，不是 NX/LR 真值对照；实际 ACR 验证另列。中性偏色的大面积影响、细节遮蔽与美观度不是一个平均 ΔE 能表达的。

色彩断层、拟合色差和机身差异均是已知问题。数值不能代替实际 LR 验收，尤其是天空、焦外和 200% 强度。JPEG 和 8 位显示预览本身也可能制造或隐藏断层。完整定义见 [English](../en/metrics.md)，版本 0.2.0。

Release 0.2.0 与网站默认均为 Y8（16 控制点平滑样条，采样成 32³ 表）；网站保留 Y7 和更早版本对比。

2026-10-10 复核：Y7 中 58 款仍有少量条纹，网站用灰色三角标记（标记描述的是 Y7）。这 58 款已用 Y8 在多张实拍上复查，未见条纹；其余 178 款未逐一复查。无论有无标记，都不等于所有场景无条纹。

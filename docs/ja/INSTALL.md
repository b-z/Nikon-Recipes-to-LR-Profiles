# 0.2.0 プロファイルの読み込み

1. ZIP を展開し、LR / Camera Raw のプロファイルブラウザーで「プロファイルを読み込み」を選び、`profiles/` の `.xmp` を指定します。別の DCP やインストーラーは不要です。
2. 表示されない場合は LR を再起動し、**Nikon Recipes LR 0.2** を開きます。
3. 適用量は 0〜200% です。控えめな効果なら 30〜50% から試し、露光量や WB の編集を続けます。

236 種のニコン変換はすべて **Y8** です。滑らかなスプラインで当てはめ、32³ RGB テーブルにサンプリングしたもので、チャート精度を少し犠牲にして階調の滑らかさを優先しています。前版 Y7 で段差が残っていた 58 種は、作者が Y8 で複数の実写を確認し、段差は見られませんでした。残る 178 種は Y8 で個別には確認していません。空、ボケ、高い適用量での色の段差は引き続き既知のリスクです。Nikon Z8 のみ検証済みです。

0.2.0 は名前、グループ、UUID が新しく、0.1 と併用できます。不要になったら **Nikon Recipes LR 0.1** のプロファイルを削除してください。

各プロファイルと `manifest.json` に元の作者と計測を記載しています。元の NP3 は同梱せず、https://github.com/shouryan01/Nikon-Recipes または作者から入手してください。ツールと独自の変換リソースは同梱 MIT / PROFILE_LICENSE、写真には別の条件が適用されます。富士シミュレーション変換は含まれません。

# 0.1.0 プロファイルの読み込み

1. ZIP を展開し、LR / Camera Raw のプロファイルブラウザーで「プロファイルを読み込み」を選び、`profiles/` の `.xmp` を指定します。別の DCP やインストーラーは不要です。
2. 表示されない場合は LR を再起動し、**Nikon Recipes LR 0.1** を開きます。
3. 適用量は 0〜200% です。控えめな効果なら 30〜50% から試し、露光量や WB の編集を続けます。

236 種のニコン変換（19 YC7 + 217 YC4）を収録します。空、ボケ、高い適用量での色の段差は既知の問題です。Nikon Z8 のみ検証済みです。以前の評価では YC7 の 18 種が許容され、Bleach Blue に段差が残りました。すべてのレシピや写真を保証するものではありません。富士シミュレーション変換は含まれません。

各プロファイルと `manifest.json` に元の作者と計測を記載しています。元の NP3 は同梱せず、https://github.com/shouryan01/Nikon-Recipes または作者から入手してください。ツールと独自の変換リソースは同梱 MIT / PROFILE_LICENSE、写真には別の条件が適用されます。

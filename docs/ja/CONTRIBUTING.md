# 貢献方法

カメラ校正、段差の改善、テスト、翻訳への貢献を歓迎します。コード、コメント、主要文書は英語とし、中国語・日本語の報告も歓迎します。

1. レシピとバージョン、適用量、カメラ、Adobe のバージョンと、公開可能な小さな切り抜きまたは合成テストを添えて問題を報告します。
2. 一つの問題に絞って修正し、`python -m unittest discover -s tests -v` を実行します。
3. PR に変更後の挙動、検証、学習用と独立検証用データの区別、素材の出典と制限を記載します。

コードと独自文書の貢献は MIT で、別途 CLA は不要です。元の NP3 コレクション、Adobe SDK、私的ログ、個人パス、許可のない写真を追加しないでください。富士シミュレーションは対象外です。単一の写真や ΔE だけで段差が解消したと結論づけず、色空間全体の監査を保持してください。

[英語原文](../../CONTRIBUTING.md)に対応、バージョン 0.1.0。

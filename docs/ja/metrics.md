# スコアと既知の問題

主なフィットスコアは、配布テーブルを既存チャートで評価した CIEDE2000 です。Adobe RGB から D65 Lab に変換し、kL=kC=kH=1 とします。入力または目標のいずれかのチャンネルが <0.0005 または >0.999 のパッチを除外します。平均、中央値、p95、サンプル数を各レシピに記録します。独立した実写真の評価ではありません。YC7 の過去の留保チャート結果も、新しい撮影シーンとは異なります。

段差リスクは 32³ テーブルの四面体内部およびセル間の 351,726 面で RGB の導関数の変化を計測した p99、最大値、RMS です。構造的なリスクであり、目に見える段差の数、ΔE、普遍的な合格基準ではありません。写像が連続でも傾きの急変が輪郭として見えることがあります。

LeicaSTD、At Dusk、Blue Hour はディテール設定を無効にした NX 基準を使用し、他の過去チャートでは設定が統一されていません。各レシピに明記します。4 枚の比較は通常 Adobe Standard 出力への数値プレビューで、NX の正解比較ではありません。実際の ACR 検証は別記します。広い中性色の色かぶり、テクスチャによる遮蔽、美しさは平均 ΔE だけでは表現できません。

段差、色調誤差、機種差は既知の問題です。空、ボケ、200% の強度では実際の LR でも確認してください。8 ビット JPEG プレビューも段差を追加または隠す場合があります。[英語の詳しい定義](../en/metrics.md)、バージョン 0.1.0。

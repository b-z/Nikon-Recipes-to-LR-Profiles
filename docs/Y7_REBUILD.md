# Full-library Y7 rebuild

All 236 Nikon recipes use the same bounded native tetrahedral 32³ fitter with regularization 0.5. The previous 19 Y7 tables are reproduced exactly; the other 217 are newly refitted. Fuji simulations are excluded.

Warning icons now reflect the 2026-10-10 Y7 review: 58 recipes retain some banding. Lower structural risk does not certify absence of visible banding. The gallery preserves previous conversions for A/B comparison.

## Aggregate results

- Existing Y7 tables reproduced exactly: 19/19.
- Former YC4 profiles with lower face-jump p99: 217/217.
- Median face-jump p99, former YC4 group: 0.842 → 0.513.
- Median change in chart mean ΔE, former YC4 group: +0.073.

## Validation

All 236 tables were decoded from their delivered XMP and checked for shape, finite bounded values, UUID, fingerprint and file checksum. Camera Raw checks cover 24Look, Bleach Blue and Filmic on Banding test 1; see acr_validation.json. Chart scores are not independent real-scene validation. Each profile uses the same train/test split as the original Y7 run.

GitHub release archives remain the previous version until explicitly updated; current per-recipe gallery downloads contain this Y7 rebuild.

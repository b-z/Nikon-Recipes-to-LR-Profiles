# Security policy

The tools read untrusted files (NP3 recipes, XMP profiles, TIFF images) and the website serves downloads. If you find a vulnerability, such as a crafted file that causes code execution or writes outside the requested output path, please report it privately to the maintainer at the email address on [@b-z's GitHub profile](https://github.com/b-z) rather than opening a public issue.

Please include the affected version, a description, and a minimal file or steps to reproduce. Only the latest release and the `main` branch receive fixes.
